# Секреты и чувствительные данные

Статус: принято
Дата: 2026-09-11

## Запрещено хранить в Git

- Telegram bot token;
- SSH private keys;
- пароли сервера и БД;
- S3 access keys;
- cookie/session secrets;
- PIN карт;
- production dumps;
- неанонимизированные реестры и Telegram exports;
- полные карточные данные без отдельного утверждённого режима.

## Разрешённые references

- имя переменной, например `TELEGRAM_BOT_TOKEN`;
- bot username;
- secret storage path без значения;
- public key;
- checksum исходного файла;
- обезличенные fixtures.

## Правила

- отдельные secrets для local, staging и production;
- минимальные права;
- rotation после раскрытия или смены участника;
- секрет не выводится в log/error;
- config endpoint не возвращает секреты;
- токен, ранее опубликованный в переписке, должен быть перевыпущен до production;
- PIN из `Физ!C:C` книги «Мотобелки» не мигрирует в систему.

## Карточные данные

Владелец процесса запросил полный PAN, банк и ФИО владельца. Для первого запуска это требование к бизнес-карточке, **не разрешение хранить PAN в открытом виде**. Основная БД хранит `card_id`, `bank_id`, маску/`last4`, статус, отдельно защищаемое ФИО и ссылку `pan_vault_ref` на зашифрованный PAN в изолированном хранилище либо у специализированного провайдера. Если обоснован доступ к полному PAN, он даётся только роли с документированной необходимостью, на короткое время, с отдельным аудитом раскрытия. Отображение по умолчанию — маска. PIN и CVV не мигрируют и не хранятся.

Согласно [разъяснению PCI SSC о маскировании и хранении PAN](https://www.pcisecuritystandards.org/faqs/1146/), маска на экране не защищает полный номер, если он всё равно хранится электронно; [PCI SSC также указывает](https://www.pcisecuritystandards.org/faqs/1492/) на необходимость сделать PAN нечитаемым при хранении и обосновывать расширенный показ. Перед production нужны документированная необходимость полного PAN, оценка области PCI DSS, модель угроз, режим ключей/резервных копий и квалификация обработки персональных данных. Оценка соответствия стандартам и российскому праву пока не выполнена. Образец CSV содержит только маскированные номера; не пытаться восстановить отсутствующий PAN.
