# Сверка

Статус: проект
Дата: 2026-09-11

## Принцип

Сверка сравнивает ledger с независимым наблюдением и не исправляет историю автоматически.

```text
расчётный остаток − фактический остаток = расхождение
```

## Объекты сверки

- карта;
- наличные отдельно у каждого сборщика или другого фактического хранителя (`custodian_id`);
- наличные у главного администратора;
- деньги в пути;
- задолженность по мерчанту;
- totals исходного реестра и применённых операций.

## Карта

`CardBalanceObservation` содержит card_id, observed_amount, observed_at, source, reporter и evidence. Разница с ledger создаёт `ReconciliationItem`.

## Касса

Модель повторяет полезную часть листа `КАССА`: opening + inflows − outflows = expected closing; факт вводится отдельно, разница расследуется.

Для сборщиков сверка выполняется по каждому `custodian_id`. Общая сумма по операционисту не заменяет индивидуальные остатки сборщиков.

## Закрытие расхождения

Допустимые результаты:

- найдено пропущенное событие и опубликована обычная операция;
- найдена ошибочная операция, выполнены reversal и replacement;
- подтверждена комиссия/расход/потеря и опубликовано соответствующее событие;
- observation признано ошибочным, создано новое наблюдение;
- расхождение остаётся открытым с владельцем и сроком.

Прямая корректировка баланса запрещена.

## Остатки в интерфейсе — согласовано 2026-10-01

В разделе «Остатки» верхняя карточка «На картах» показывает две строки: учётный остаток по счёту 1100 и фактический — сумму последних сообщённых остатков каждой карты. Используется то же последнее наблюдение, которое показано в таблице карт: по времени наблюдения, при совпадении времени — по ID. Учитываются все карты, включая выведенные из работы.

Карта без наблюдения не считается картой с фактическим нулём. Если наблюдения есть не у всех карт, карточка показывает количество карт с данными относительно общего количества; если наблюдений нет, выводится «Нет данных». Внесённый нулевой остаток показывается как `0,00 ₽`. Например, последние наблюдения `123,45 ₽` и `−2,34 ₽` при третьей карте без данных дают `121,11 ₽` с подписью «данные по 2 из 3 карт».

Это сумма наблюдений на разные моменты времени, а не подтверждённая сумма денег на текущую дату. После новых операций наблюдения не пересчитываются автоматически. Общая сумма на картах и у хранителей по-прежнему использует учётный остаток; отображение фактического не создаёт проводок.
