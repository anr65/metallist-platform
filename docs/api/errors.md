# Ошибки API и интерфейса

Статус: реализовано в коде; требуется выпуск на прод.
Обновлено: 2026-09-22.

Все web API при ошибке возвращают JSON `{"code":"INSUFFICIENT_BALANCE","error":"Недостаточно денег…"}` с соответствующим HTTP-статусом. `code` — стабильный идентификатор для клиента; `error` — готовый русский текст. Каталог и тексты находятся в `cmd/platform/errors.go`. Клиент читает их через `ui/src/api-errors.js`; при недоступности сервера или невалидном ответе показывает отдельное русское сообщение. Неизвестные внутренние ошибки и тексты базы данных в интерфейс не выводятся.

| Код | Ситуация | Действие пользователя |
| --- | --- | --- |
| `INSUFFICIENT_BALANCE` | Подтверждаемая сумма превышает учётный остаток у ответственного или на карте | Проверить остаток и фактическую сумму; подтвердить меньшую сумму либо сначала отдельно оформить реальное пополнение |
| `INVALID_AMOUNT`, `AMOUNT_MISMATCH` | Некорректная или неподтверждённая сумма | Исправить сумму |
| `STALE_PREVIEW`, `CONFLICT` | Данные изменились после открытия формы | Обновить данные и повторить действие |
| `ALREADY_EXISTS`, `RELATED_RECORD` | Конфликт связанной записи | Проверить запись и обновить страницу |
| `FORBIDDEN`, `UNAUTHORIZED` | Недостаточно прав или завершился сеанс | Войти снова либо обратиться к главному администратору |
| `INTERNAL_ERROR`, `DATABASE_ERROR`, `NETWORK_ERROR`, `BAD_RESPONSE` | Сбой сервера, базы или связи | Повторить позже; если повторяется — передать время и действие поддержке |

Черновик денежной операции не меняет остаток. Проверка достаточности средств для передачи происходит при её подтверждении главным администратором; до этого черновик может быть сохранён. Это следует [правилу проводок](../accounting/posting-rules.md#передача-главному-администратору).
