# Глоссарий

Статус: проект
Дата: 2026-09-11

| Термин | Значение | Статус |
|---|---|---|
| Металлист | Компания, сопровождающая финансовый цикл и получающая комиссию | подтверждено |
| Мерчант | Компания металлоприёмки, финансирующая карты и рассчитывающаяся с металлосдатчиками | подтверждено |
| Металлосдатчик | Физическое лицо, сдавшее металл мерчанту и ожидающее оплату | подтверждено |
| Карта | Платёжный инструмент, используемый в операционном цикле | подтверждено |
| Материал / материалы | Сленговое название набора карт, передаваемого для пополнения или обработки | подтверждено |
| Material batch | Целевая сущность набора карт; аналитическая группировка, не ledger-счёт | проект |
| Реестр мерчанта | XLSX или иной документ с фактом/заявлением о суммах, направленных на карты | подтверждено |
| Операционист | Участник, организующий снятия и передающий сведения через Telegram | подтверждено |
| Сборщик | Участник, физически работающий с картами и банкоматами; полученные им наличные учитываются отдельно за ним | подтверждено |
| Главный администратор | Получает наличные, возвращает средства мерчантам, сообщает расходы и инъекции | подтверждено |
| Бухгалтер | Вручную фиксирует часть операций главного администратора и выполняет сверку | подтверждено |
| Пополнение | Факт поступления денег на карту | подтверждено |
| Снятие | Факт выдачи наличных банкоматом с карты | подтверждено |
| Наблюдение остатка | Сообщённый банкоматом или оператором фактический остаток; не замена ledger-баланса | принято |
| Передача наличных | Смена ответственного хранителя денежных средств | принято |
| Возврат мерчанту | Передача денег главным администратором мерчанту; в этот момент долг уменьшается | подтверждено |
| Комиссия | Процент от общей суммы реестра по тарифу мерчанта, денежный результат с точностью до копейки; удерживается из суммы к возврату и признаётся выручкой при подтверждении. Чистая прибыль дополнительно учитывает расходы | подтверждено |
| Тариф мерчанта | Сохранённая процентная ставка клиента с двумя знаками после запятой, по которой автоматически рассчитывается комиссия от общей суммы реестра; денежный итог округляется до копейки по `ROUND_HALF_UP` | подтверждено |
| Транзитный оборот | Основная сумма мерчанта, проходящая через карты и наличные; не выручка «Металлиста» | принято |
| Кредиторская задолженность | Чистая сумма, подлежащая возврату мерчанту после удержания комиссии | подтверждено |
| Дебиторская задолженность мерчанта | Сумма возвратов сверх общего оставшегося долга мерчанту; может возникнуть при прямой переплате или после сторно реестра | подтверждено |
| Инъекция | Внесение внешних средств; собственные средства по умолчанию возвратны, прощённый долг может перейти в капитал без нового прихода денег. Выражение «инъекция за счёт старой дебиторки» означает фактический возврат денег должником и учитывается отдельно как погашение дебиторки | подтверждено частично |
| Невыясненное поступление | Подтверждённый излишек с ещё не установленным основанием; не выручка | подтверждено |
| Ledger | Неизменяемый журнал сбалансированных проводок | принято |
| Journal entry | Хозяйственная запись, объединяющая минимум две проводки | принято |
| Posting | Дебетовая или кредитовая строка journal entry | принято |
| Сторно | Новая запись, нейтрализующая ранее опубликованную ошибочную запись | принято |
| Opening balance | Агрегированное начальное состояние на дату перехода без восстановления всей истории | принято |
| Сверка | Сопоставление расчётного состояния с независимым фактическим наблюдением | принято |
