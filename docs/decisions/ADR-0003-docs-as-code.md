# ADR-0003: Docs as code

Статус: принято  
Дата: 2026-09-11

## Контекст

Бизнес-правила и архитектура должны быть одинаково доступны людям и AI-агентам и меняться вместе с кодом.

## Решение

Хранить каноническую базу знаний в Markdown в этом репозитории. Существенные изменения проходят pull request вместе с кодом. Внутренний сайт может быть построен из этих файлов, но не становится отдельным источником истины.

## Последствия

- история решений доступна в Git;
- документацию можно проверять в CI;
- AS IS и TO BE разделены;
- секреты и исходные чувствительные файлы в docs запрещены;
- нужен поддерживаемый индекс и контроль устаревания.
