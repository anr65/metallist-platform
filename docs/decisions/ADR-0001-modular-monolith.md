# ADR-0001: Modular monolith

Статус: принято
Дата: 2026-09-11

## Контекст

Продукт имеет связанные финансовые операции, небольшую начальную команду и требует быстрой реализации с транзакционной целостностью.

## Решение

Создать один Go application с внутренними доменными модулями, одной PostgreSQL и отдельными web/bot adapters. Разделение обеспечивается пакетами и публичными application commands, а не сетевыми микросервисами.

## Последствия

- проще обеспечить одну транзакцию business event + ledger;
- проще deployment и локальная разработка;
- модули должны соблюдать границы;
- выделение сервиса возможно позже по реальной нагрузке, но не проектируется заранее.
