# ADR-0002: Double-entry ledger

Статус: принято
Дата: 2026-09-11

## Контекст

Нужно одновременно объяснять деньги на картах, наличные у разных лиц, кредиторку, комиссию, расходы, расхождения и исправления.

## Решение

Использовать управленческий double-entry ledger. Каждая опубликованная запись сбалансирована и неизменяема. Исправления создаются reversal/replacement.

## Последствия

- остатки и долг выводятся из postings;
- transit principal не смешивается с revenue;
- требуется строгий posting API и idempotency;
- отчёты получают единый финансовый источник;
- пользовательский workflow остаётся отдельным от accounting state.
