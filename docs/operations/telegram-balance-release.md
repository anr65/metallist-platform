# Остаток наличных в Telegram-итоге — 27.10.2026

Статус: подготовлено к выпуску по запросу владельца; production-результат фиксируется ниже после проверки.

## Изменение

Итоги новых проведённых Telegram-снятий, расходов/зарплат, handover, transfer и личных repay содержат `Баланс: … ₽`. [Точная семантика и примеры](../integrations/telegram.md#баланс-в-итоге-операции--27102026). В группе показан остаток автора/отправителя, в личном итоге transfer — получателя. Снимок из postings сохраняется в payload той же транзакцией, после всех финансовых записей операции; повторная доставка не считывает более поздний баланс. Комиссия с карты не уменьшает наличные. Резервы не вычитаются из учётного остатка.

Изменены только представление, сохранение снимка при существующем подтверждении и форматирование отрицательных денег. Новых счетов, проводок, разрешений, миграций или backfill нет; исторические сообщения без снимка сохраняют прежний формат. Web-приём прежнего Telegram-handover и chief-приём transfer также сохраняют снимок. При ошибке получения снимка финансовая транзакция откатывается.
