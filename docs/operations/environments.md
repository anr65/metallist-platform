# Окружения

Статус: `main` развёрнут на production по решению владельца процесса от 2026-09-21
Дата обновления: 2026-09-21

## Local

- локальные контейнеры;
- синтетические данные;
- отдельная disposable PostgreSQL;
- локальные или тестовые интеграционные credentials.

## Production

- домен `metallcash.work` направлен на подготовленный сервер;
- HTTPS обслуживает Caddy;
- вход на сервер только `deploy` по SSH-ключу;
- root login и password authentication отключены;
- UFW разрешает SSH, HTTP и HTTPS;
- рабочий каталог `/opt/metallist-platform`;
- приложение `metallist-platform.service` и Caddy запущены через systemd; база `metallist_demo` на этом хосте содержит рабочие данные и считается production независимо от исторического имени;
- ветка `main` является единственным источником production-релизов. Любые изменения данных, схемы и развёртывания требуют обращения с ними как с production.

Ежедневный локальный backup настроен; offsite backup, алертинг и CI/CD остаются отдельными задачами.

На 2026-09-21 в рабочем окружении 113 активных карточек карт, у 109 полные номера сохранены зашифрованно. Экспорт запросов создаёт XLSX с этими номерами только при авторизованном скачивании. Четыре оставшиеся карточки с историческими масками не доступны для запроса до внесения полных номеров.

## Правило безопасности тестов

Перед любой database-capable проверкой нужно доказать, что target является выделенной disposable test database. Название переменной `TEST_DATABASE_URL` само по себе доказательством не является. `metallist_demo` на хосте никогда не использовать для тестов, сбросов или экспериментов с миграциями.
