# Окружения

Статус: `demo-v1` и база на хосте являются production по решению владельца процесса от 2026-09-21
Дата обновления: 2026-09-21

## Local

- локальные контейнеры;
- синтетические данные;
- отдельная disposable PostgreSQL;
- локальные или тестовые интеграционные credentials.

## Production (историческое имя demo)

- домен `metallcash.work` направлен на подготовленный сервер;
- HTTPS обслуживает Caddy;
- вход на сервер только `deploy` по SSH-ключу;
- root login и password authentication отключены;
- UFW разрешает SSH, HTTP и HTTPS;
- рабочий каталог `/opt/metallist-platform`;
- приложение и Caddy запущены через systemd; база `metallist_demo` на этом хосте содержит рабочие данные и считается production независимо от исторического имени;
- ветка `demo-v1` является production-веткой. Любые изменения данных, схемы и развёртывания требуют обращения с ними как с production.

Наличие или отсутствие CI/CD, offsite backup, алертинга и отдельного хранилища исходных документов требует отдельной проверки перед изменениями; исторические сведения о демо не являются основанием считать данные синтетическими.

## Правило безопасности тестов

Перед любой database-capable проверкой нужно доказать, что target является выделенной disposable test database. Название переменной `TEST_DATABASE_URL` само по себе доказательством не является. `metallist_demo` на хосте никогда не использовать для тестов, сбросов или экспериментов с миграциями.
