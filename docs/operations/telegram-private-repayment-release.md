## Доставка и диагностика

Очередь: `SELECT draft_id,state,attempts,next_attempt_at,last_error FROM telegram_repayment_notifications WHERE state='pending' ORDER BY next_attempt_at;`. Не исправлять postings ради доставки. Повторную доставку после исправления настройки можно запланировать UPDATE только `next_attempt_at`, не создавая новый repayment. При смене группы очередь не уходит автоматически в новую группу: требуется отдельное решение по уже сохранённым уведомлениям. Возможен повтор Telegram-сообщения при потере подтверждения доставки, финансовый повтор исключён.
