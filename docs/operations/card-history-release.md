## Выпуск и откат

Опубликовать проверенный commit в main обычным fast-forward push, запустить штатный `scripts/deploy-production.sh` с точным SHA. Скрипт проверяет вершину main, собирает новый release, атомарно переключает current и при неуспехе restart/health возвращает предыдущий release. При ручном откате вернуть current на `29fdfd7a4540dab02bcffbee4bf3c6c6f51d11cd` и перезапустить сервис; схему 33 и данные сохранить.

После переключения проверить local/public health, active/running, отсутствие ошибок сервиса и входящие запросы API.
