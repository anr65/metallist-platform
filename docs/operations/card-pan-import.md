# Загрузка полных номеров существующих карт

Дата: 2026-09-21.

Команда `platform import-card-pans` принимает через стандартный ввод только полные номера, по одному на строку. Она сверяет контрольную цифру, уникальную маску и существующую активную карточку, а затем записывает номер в зашифрованное хранилище и событие `card_pan_import` в аудит. Перед первой записью проверяется весь пакет; повторный запуск с тем же пакетом ничего не меняет. Полные номера нельзя помещать в аргументы команд, Git, логи или документацию.

По сообщению владельца процесса получено 109 номеров. Все 109 сопоставлены с существующими карточками по маске; новых карточек в БД не создавали. Один исходный номер не прошёл проверку контрольной цифры. Владелец уточнил последнюю цифру `2`; у существующей карточки без финансовой истории маска исправлена с `220015******6423` на `220015******6422` с сохранением ID и четырёх назначений сотрудникам. Исправление записано в аудит как `card_mask_corrected`.

В хранилище сохранены 109 полных номеров. Повторный запуск проверил их расшифровку и соответствие: `сохранено: 0; уже было сохранено: 109`. Всего в БД 113 активных карточек; четыре исторические карточки остаются без полного номера. У карт нет проводок и наблюдений: расчётные остатки равны нулю. Суммы, указанные после тире в исходном сообщении, не импортировались и не создавали финансовых событий.

До и после импорта запущен production backup. Последняя копия содержит 109 зашифрованных файлов карт; все компоненты набора прошли SHA-256 проверку, каталог PostgreSQL dump прочитан. Исходный список полных номеров не сохранялся в репозитории или открытых таблицах БД.
