# Исправление загрузки ответного реестра 21.09.2026

Статус: исправлено на production 2026-09-21.

Оператор загрузил XLSX для мерчанта и связанного запроса карт. Сервер сохранил исходный файл и предварительный реестр, но интерфейс после асинхронного ответа обратился к `event.currentTarget`, который уже был `null`; поэтому показал техническую ошибку и не обновил список. Дополнительно проверка назначения карт оператору ошибочно отметила три из пяти строк `card_not_assigned`. Правило назначения относится к снятию и расходу с карты, не к загрузке ответного реестра.

Код сохраняет ссылку на форму до асинхронной операции, обновляет список после ответа и показывает число проблемных строк. При сопоставлении строк реестра проверка назначения оператору снята; проверка выбранного запроса и однозначности карты остаётся. Регрессионный тест загружает связанный реестр от имени оператора без назначенной ему карты.

Исходный файл в production не загружается повторно: его SHA-256 совпал с приложенным пользователем файлом. Закрытая резервная копия проверена и восстановлена в отдельную базу `metallist_registry_fix_restore_test`. На ней сценарный SQL `scripts/repair-registry-20260921.sql` исправил только три ошибочные строки предварительного просмотра, пересчитал итог, повысил версию и записал безопасный аудит; исходный файл и проводки остались прежними. SQL проверяет точный реестр, хеш, версию, статус, состав строк, однозначность масок и итог, иначе прерывает транзакцию. Перед применением к production требуется повторно проверить её состояние и сохранить свежую резервную копию.

Выпуск: перед коррекцией создана и проверена копия `/var/backups/metallist-platform-protected/20260921T162148Z`. Релиз `22c4f93cc626281232fed99a7160a3ad8ffddb60` установлен из `main`; затем тот же проверенный SQL применён к рабочей базе. Результат: предварительный реестр версии 2, пять строк с однозначными картами, ноль ошибок, исходный SHA-256 прежний, финансовые проводки не изменились. Сервис и публичные `/health` и `app.js` отвечают. После коррекции создана и проверена копия `/var/backups/metallist-platform-protected/20260921T162415Z`; проверочная база удалена.
