# Редактирование ФИО и телефона: право прикладной роли

29.09.2026 при сохранении существующего контакта приложение получило PostgreSQL `42501`: роль `metallist_demo_app` имела `SELECT` и `INSERT` для `payment_contacts`, но не `UPDATE`. Интерфейс показал общую ошибку сохранения. Неудачная попытка не изменила контакт.

Миграция `schema/019_payment_contact_edit_grant.sql` выдаёт прикладной роли только `UPDATE` колонок `full_name` и `phone` и повышает версию схемы с 18 до 19. Она не меняет данные контактов, финансовые проводки и другие права.

Перед применением к рабочей базе проверить цель (`metallist_demo` на `deploy@167.233.162.67`), версию 18, сделать свежую проверенную резервную копию и проверить миграцию на отдельной disposable базе с прикладной ролью. Применять файл одной транзакцией с `ON_ERROR_STOP=1`. После применения проверить версию 19 и права на обе колонки; сохранение контакта должно проходить через обычный интерфейс с аудитом.
