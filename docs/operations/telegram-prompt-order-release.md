Статус: подготовлено по уточнению владельца после проверки чата.

## Объём

Прежний релиз редактировал hint в preview/итог, поэтому результат оказывался выше вводимых карт. Новый порядок: отправить отдельный preview после принятого сообщения пользователя, затем удалить hint; preview превратить в финальный статус на месте. Применено к withdraw/expense/handover/transfer и личному repay; подсказки card_status/block_card также удаляются после принятого следующего шага. Исходные сообщения участников сохраняются. Два подтверждения transfer, одно подтверждение Тони для нового handover, права, точные суммы, резервы, наблюдения и posting boundary неизменны.

Схема 030 добавляет только пустую очередь удаления собственных подсказок и grants на неё. Денежные таблицы, исходные документы и существующие карточки не мигрируются. Новый бинарник требует 030 до запуска, прежний совместим с добавочной таблицей. Старые канонические preview/итоги не удаляются.

Обработка повтора уже принятого обычного сообщения проверяет сохранённые update/from/chat: после завершения диалога допускается только известный повтор для восстановления preview. Произвольная переписка по-прежнему игнорируется. Удаление ставится в очередь после успешной отправки preview и переживает сбой API/перезапуск. Ошибка удаления не препятствует подтверждению и не повторяет деньги.
