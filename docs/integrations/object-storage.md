# Объектное хранилище

Статус: проект
Дата: 2026-09-11

## Назначение

S3-совместимое хранилище содержит оригинальные XLSX, изображения, подтверждения, экспортированные отчёты и резервные копии. PostgreSQL хранит метаданные и storage key, а не большие файлы.

## Требования

- отдельные buckets или префиксы staging/production;
- запрет публичного доступа;
- server-side encryption;
- versioning;
- lifecycle и retention;
- checksum при загрузке;
- временные signed URLs;
- отдельные credentials с минимальными правами;
- audit доступа провайдера, если доступен.

Удаление объекта, связанного с posted event, требует утверждённой retention-процедуры и не удаляет metadata/audit trail.
