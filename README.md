# Metallist Platform

Система управленческого учёта денежных операций компании «Металлист».

Основная задача продукта — показать, где находятся сопровождаемые деньги, сколько компания должна каждому мерчанту, какую комиссию заработала и какие расходы понесла. Транзитный оборот мерчанта не считается выручкой «Металлиста».

Платформа содержит Go-приложение, PostgreSQL ledger и браузерный кабинет. `metallcash.work` является рабочим production-сайтом. Переключение источника релизов на `main` описано в [плане перехода](docs/operations/production-cutover.md).

## Архитектура

- modular monolith;
- Go API;
- PostgreSQL;
- встроенный браузерный кабинет;
- Telegram bot;
- закрытый каталог исходных документов (до выбора S3-провайдера);
- double-entry ledger как источник финансовых остатков.

`go build ./cmd/platform` собирает приложение. Базовая схема находится в `schema/001_initial.sql`, добавочные миграции — в `schema/002_*.sql`–`schema/008_*.sql`. Для рабочего запуска нужны `DATABASE_URL`, `APP_ENV=production`, `DOCUMENT_DIR`, `PAN_VAULT_DIR` и `PAN_KEY_FILE`. Рабочая БД сохраняется при переходе на `main`; миграции применяются по [плану перехода](docs/operations/production-cutover.md) после проверки цели и восстановления резервной копии. Секреты в репозитории не хранятся.

Архитектурные решения зафиксированы в `docs/decisions/`.
