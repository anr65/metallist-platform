# Metallist Platform

Система управленческого учёта денежных операций компании «Металлист».

Основная задача продукта — показать, где находятся сопровождаемые деньги, сколько компания должна каждому мерчанту, какую комиссию заработала и какие расходы понесла. Транзитный оборот мерчанта не считается выручкой «Металлиста».

Сейчас репозиторий содержит первоначальную базу знаний и проектные навыки Codex. Программный каркас будет создан после подтверждения открытых бизнес-решений.

## Начало работы

1. Прочитать [индекс документации](docs/00-index.md).
2. Ознакомиться с [реестром источников и статусов](docs/status-and-sources.md).
3. Перед финансовыми изменениями проверить [открытые вопросы](docs/open-questions.md).
4. Следовать инструкциям [AGENTS.md](AGENTS.md).

## Предварительная архитектура

- modular monolith;
- Go API;
- PostgreSQL;
- React admin;
- Telegram bot;
- S3-совместимое хранилище документов;
- double-entry ledger как источник финансовых остатков.

Архитектурные решения зафиксированы в `docs/decisions/`.
