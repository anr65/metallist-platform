# Metallist Platform

Система управленческого учёта денежных операций компании «Металлист».

Основная задача продукта — показать, где находятся сопровождаемые деньги, сколько компания должна каждому мерчанту, какую комиссию заработала и какие расходы понесла. Транзитный оборот мерчанта не считается выручкой «Металлиста».

Первая демонстрационная версия содержит Go-приложение, PostgreSQL ledger и браузерный кабинет. Описание реализованных и отложенных сценариев: [demo-v1](docs/operations/demo-v1.md).

## Архитектура

- modular monolith;
- Go API;
- PostgreSQL;
- встроенный браузерный кабинет;
- Telegram bot;
- закрытый каталог исходных документов (до выбора S3-провайдера);
- double-entry ledger как источник финансовых остатков.

`go build ./cmd/platform` собирает приложение. Базовая схема находится в `schema/001_initial.sql`, добавочная миграция запросов карт — в `schema/002_payment_requests.sql`. Для первого запуска нужны `DATABASE_URL`, `APP_ENV`, `DOCUMENT_DIR` и два защищённых файла с начальными паролями. Миграция demo-БД выполняется только по [процедуре развёртывания](docs/operations/demo-v1.md) после проверки цели и восстановления резервной копии. Никаких секретов в репозитории нет.

Архитектурные решения зафиксированы в `docs/decisions/`.
